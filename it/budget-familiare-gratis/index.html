Come usarlo in Google Sheets

  1. Scarica il file .xlsx.
  2. Vai su drive.google.com, clicca su Nuovo › Caricamento di file e scegli il modello.
  3. Apri il file e scegli File › Salva come Fogli Google.
  4. Scrivi solo nelle celle gialle. I numeri d'esempio sono fittizi: cancellali e inserisci i tuoi.
